# Матрица оборудования iPhone 7 Plus под iOS 16

Оценки ниже предварительные. Они основаны на опыте yigitzra1n (A9 → 16.7) и на том, что для A10
есть iPadOS 16. Подтверждать их будем на этапе EVT1 через `halcyon compat` и ioreg.

| Компонент | Ожидание | Почему | Трек |
|---|---|---|---|
| Дисплей (AppleCLCD) | 🟢 вероятно | тот же T8010 DisplayPipe есть в iPadOS 16 для iPad 7 | main |
| Сенсор / 3D Touch | 🟡 нужен порт | контроллер мультитача у iPhone другой; у yigitzra1n для 6s его перелинковали из 15 | main |
| GPU / ускорение | 🟢 вероятно | AGX G9 для A10 есть в iPadOS 16 | main |
| Wi-Fi / BT | 🟡 | модули могут отличаться от iPad 7, нужны прошивки из 15 | main |
| Звук / микрофоны | 🟡 нужен порт | у iPhone свои кодек и усилитель (аналог AppleCS42L71/CS35L*) | main |
| Камеры | 🟠 сложно | ISP и сенсоры двойной камеры уникальны, тюнинг на стороне userspace | main |
| Taptic Engine | 🟡 | драйвер есть в 15; в iPadOS его нет | main |
| Кнопка Home | 🟠 | она сенсорная и работает через Taptic; связана с Mesa и SEP | main |
| Touch ID | 🔴 исследование | требует SEP, см. SEP.md | research |
| Мобильная связь | 🔴 исследование | iOS 16 для модемов MDM9645/XMM7360 не выходила | research |
| Зарядка | 🟡 | yigitzra1n понадобился свой демон зарядки | main |
| Питание / PMU | 🟡 | тот же PMU у iPad 7, уточнить | main |
| Сон | 🟠 | зависит от AOP и SEP; у yigitzra1n это заглушка `sleepd_stub` | main |

🟢 скорее всего заработает · 🟡 нужен порт или патч · 🟠 сложно · 🔴 вероятный блокер

Честно: на A9 вариант yigitzra1n работает без SEP, Touch ID, код-пароля и модема, и загружается
только tethered. Для A10 вероятен такой же исход. Если удастся больше, это будет результатом
исследования, обещать его заранее нельзя.
